# Exploratory validation experiments — Paper 275

The user's latest task requests evaluation-only validation experiments A–C and saved-result analysis D. No ArtFAE-Net/baseline training, holdout model inference, data changes or external correspondence is authorized. Costs and risks were reported before GPU execution. `protocol.json` and `validation_subset.csv` were written before model execution; checkpoint pins match the existing locked selection. `preservation_before.json` protects original manifests/checkpoints/locked outputs.

Task A uses 200 validation rows selected by a target-independent SHA-256 rule, R1 seed42, fixed original predicted classes, equal display-grid masking fractions 5/49, 10/49, 15/49 and 24/49, two replacement operators and ten random rankings per artwork. All affected visual/attribute features are recomputed; the changed template selects its exact frozen embedding from a pre-encoded 27-sentence dictionary. RISE-style uses 256 shifted smooth Bernoulli masks per image and is explicitly finite-mask exploratory, with its ranking constructed under mean fill then evaluated under both operators. Partial AUC uses raw target probability, normalized only by horizontal interval width. No 0/1 endpoints are fabricated. Interventions act on the whole pipeline; no causal ECSA or human-region claim is warranted. Native 24×24 tokens are adaptively pooled; equal 7×7 display cells are not independent exact receptive fields.

Task B holds all parameters and image/patch features fixed, permuting numerical/text pairs consistently with 20 fixed derangements over all 3,000 validation rows and five R1 checkpoints. Original cached logits must reproduce before analysis. This tests sensitivity to image–attribute misalignment, not whether retraining benefits from attributes. Report CE/F1, top1 flips and prediction total variation. CE paired-artwork intervals condition on fixed seeds and permutations.

Task C runs fresh independent R1/probe workers sequentially, with the same 32 validation images, batch8, FP32 and TF32 disabled. It includes image decoding, the model's actual feature branches, head and probability transfer, synchronized on CUDA. Text is encoded per batch for the resource test, unlike the exact dictionary optimization in Task A. Record component timings, batch median/p95, throughput, CUDA allocated/reserved peaks and process RAM, including model-load RAM. Loading the common full CLIP object for the probe is a controlled benchmark choice, not a minimum-memory optimized deployment.

Task D reads existing holdout logits/metadata only. Means by style, artist overlap and tie status are descriptive, composition-dependent and outside H1–H5. No new mapping or split is built. Task E remains a separate proposed frozen-ResNet training plan; no baseline is trained.

Validation was previously used for checkpoint selection and includes 16 known training reproductions. The selected 200 may include those cases; their overlap count is recorded rather than silently excluding them. All new results are exploratory, not additions to the five internally locked hypotheses, external robustness or explanation validation against humans.

The pilot processed 16 modified images at approximately 59 images/s, peak allocated CUDA approximately 2.4 GB. Planned full Task A has 89,800 image encodings including the RISE comparator; actual wall time includes decoding/attributes. New outputs stay under this directory; no modified painting is written back to the dataset.
