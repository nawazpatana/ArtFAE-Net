# ArtFAE-Net human-evaluation study (English / 繁體中文)

A **private** study. Participants rate 20 artworks from the ArtFAE-Net fresh holdout:
- their own emotion first (blind)
- then the model's estimate
- an unlabelled R1-vs-R3 comparison
- optionally, the attention overlay

All model outputs are precomputed (`precomputed/`) and frozen (`stimuli_FROZEN.txt`; the app refuses to start if
any file differs). It runs on **CPU basic** hardware with no model weights, as a Docker Space (Streamlit on port 7860).

## Settings (Space → Settings → Variables and secrets)

| kind | name | value |
|---|---|---|
| Secret | `HF_TOKEN` | a fine-grained token with **write** access to the two study dataset repos only |
| Variable | `STUDY_MODE` | `pilot` (default) or `production` |
| Variable | `DATASET_REPO` | `nawazishpatana/artfae-study-pilot` in pilot mode, `nawazishpatana/artfae-study-responses` in production |
| Variable | `CONSENT_APPROVED` | production only: `1`, set once the ethics-approved consent text is deployed |

**Safety checks.** The app refuses to start if:
- `DATASET_REPO` does not match `STUDY_MODE`
- `HF_TOKEN` is missing
- `STUDY_MODE=production` is set without `CONSENT_APPROVED=1`

**Pilot mode** shows "Pilot test: responses are not used for research" on every page.

## Data

- **Identity.** Each participant is a random UUID. No names, emails or IP addresses are collected.
- **Storage.** Responses are appended to JSON Lines files and pushed to the dataset every 2 minutes by
  `huggingface_hub.CommitScheduler`: `data/trials-*.jsonl` (one row per trial) and `data/participants-*.jsonl`.
  Every row records `study_mode`.
- **Restarts.** The Space disk is not persistent. Anything not yet pushed is lost on a restart.

## Build

This folder is generated by `python study/space/build.py` from the ArtFAE-Net repository.
ArtEmis vote shares (`study/private/`) are never included.
